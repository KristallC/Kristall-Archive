📊 Вывод таблиц кланов в ваших проектах через API

Вы разрабатываете собственные игры или приложения для нашего сообщества? Отличная новость! Теперь вы можете выводить актуальный рейтинг и списки кланов KristallCommunity прямо внутри своих проектов, используя наше статическое JSON-API.

💡
Как это работает?

Вся статистика кланов нашего сообщества хранится в открытом JSON-файле на наших серверах GitHub. Вы можете отправлять прямые запросы к этому файлу и использовать полученные данные как вам угодно.

1. Ссылка на источник данных

Для получения актуальных данных используйте следующую прямую raw ссылку на наш репозиторий:

https://raw.githubusercontent.com/KristallC/Kristall-Community/refs/heads/main/databases/clans.json

2. Структура получаемого JSON-файла

При запросе сервер вернет вам массив объектов. Каждая карточка клана содержит следующие поля, которые легко прочитать из кода:

  • id — уникальный текстовый идентификатор клана.
  • name — официальное название, отображаемое на сайте.
  • tag — официальный тег клана.
  • tag_color — HEX-код цвета для тега клана.
  • members_current — количество участников клана.
  • points — количество очков рейтинга клана.
  • trend — тенденция в таблице лидеров.

3. Пример реализации на JavaScript

Вы можете использовать стандартный метод fetch() для вывода данных в консоль вашего веб-приложения или скрипта:

const url = 'https://raw.githubusercontent.com/KristallC/Kristall-Community/refs/heads/main/databases/clans.json';

fetch(url)
  .then(response => response.json())
  .then(clans => {
    // Сортируем кланы по очкам (от большего к меньшему)
    clans.sort((a, b) => b.score - a.score);
    
    console.log("Топ кланов Kristall:");
    clans.forEach((clan, index) => {
        console.log(`${index + 1}. [${clan.name}] — Очки: ${clan.score}`);
    });
  })
  .catch(err => console.error("Ошибка загрузки данных:", err));
