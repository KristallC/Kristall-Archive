Ультимативный справочник по Go (Golang): От основ до бэкенда

Go — это компилируемый язык программирования со строгой статической типизацией, созданный инженерами Google. Он разработан специально для создания высоконагруженных сетевых сервисов, бэкенда и распределённых систем. Этот подробный гайд содержит весь базовый синтаксис, разбор архитектуры памяти и примеры создания реального API.

💡
Особенности компиляции в Go

Код Go компилируется напрямую в машинные инструкции целевой операционной системы. На выходе вы получаете один независимый исполняемый файл без необходимости устанавливать на сервер интерпретаторы, библиотеки или тяжелые виртуальные машины.

1. Архитектура работы Go: Как код становится программой

В отличие от скриптовых языков (Python, JavaScript), которые переводятся в машинный код прямо во время запуска, Go делает всю тяжелую работу заранее. Специальный инструмент — компилятор — берет ваш текст программы и собирает из него готовый бинарник.

[ Твой код: main.go ]
↓ Команда: go build main.go
[ Компилятор Go (Проверка синтаксиса и оптимизация) ]
↓ Генерация машинного кода
[ Готовый файл: main.exe (Windows) или main (Linux/Mac) ]

2. Анатомия программы (Hello, World!)

Любой исполняемый файл в Go должен принадлежать пакету main и содержать одноименную функцию main(), которая является официальной точкой входа в приложение.

package main

import "fmt" // Импортируем стандартный пакет для ввода-вывода текста

func main() {
    fmt.Println("Привет от Kristall Archive!")
}

3. Переменные, Константы и Типизация

В Go строгая статическая типизация: тип переменной определяется при её создании и не может меняться. Язык поддерживает явное объявление и сокращённое (с автоопределением типа).

package main

import "fmt"

const Pi = 3.14159 // Константы объявляются через ключевое слово const

func main() {
    // 1. Явное объявление с ключевым словом var
    var message string = "Бэкенд на Go"
    var version int = 1
    
    // 2. Сокращённое объявление с помощью оператора := (работает только внутри функций)
    isRelease := true // Автоматически определится как bool
    rating := 98.5    // Автоматически определится как float64

    fmt.Println(message, version, isRelease, rating)
}
Группа типов Типы данных в Go Описание
Строки string Текст в двойных кавычках, поддерживает UTF-8 из коробки.
Целые числа int, int8, int32, int64, uint Числа без дробной части. Разные размеры важны для точечной оптимизации памяти.
Дробные числа float32, float64 Числа с плавающей точкой (стандарт для бэкенда — float64).
Логический bool Принимает исключительно значения true или false.
⚠️
Жёсткие правила компилятора

Если вы импортировали пакет или создали переменную, но ни разу не использовали её в коде, Go выдаст ошибку компиляции. Язык принудительно заставляет вас писать чистый код без мусора.

4. Управляющие конструкции (Условия и Циклы)

В Go условия пишутся без круглых скобок вокруг проверяемого выражения. Важная особенность синтаксиса условий: открывающая фигурная скобка { обязана находиться на той же строчке, что и оператор условия.

package main

import "fmt"

func main() {
    score := 75

    // Классическое условие
    if score >= 90 {
        fmt.Println("Отличный результат!")
    } else if score >= 60 {
        fmt.Println("Хороший результат.")
    } else {
        fmt.Println("Нужно подтянуть знания.")
    }
}

Единственный цикл: for

В языке Go из соображений минимализма нет циклов while или do-while. Все виды итераций реализуются с помощью одного универсального цикла for.

package main

import "fmt"

func main() {
    // 1. Стандартный цикл со счетчиком
    for i := 0; i < 3; i++ {
        fmt.Println("Итерация:", i)
    }

    // 2. Аналог цикла while (только с условием выхода)
    counter := 0
    for counter < 3 {
        fmt.Println("Счетчик:", counter)
        counter++
    }

    // 3. Бесконечный цикл (выход через break)
    for {
        fmt.Println("Работаем...")
        break // Немедленный выход из цикла
    }
}

5. Функции и возврат множества значений

Функции в Go могут принимать параметры, возвращать именованные результаты, а главное — они умеют возвращать несколько значений одновременно. Это стандартный для Go способ обработки ошибок бэкенда.

package main

import (
    "errors"
    "fmt"
)

// Функция принимает два int и возвращает результат деления и ошибку
func divide(a, b int) (int, error) {
    if b == 0 {
        // Возвращаем дефолтный 0 и созданную ошибку
        return 0, errors.New("на ноль делить нельзя")
    }
    // Если всё хорошо, возвращаем результат и пустую ошибку (nil)
    return a / b, nil
}

func main() {
    result, err := divide(10, 0)
    
    if err != nil {
        fmt.Println("⚠️ Произошла ошибка:", err)
        return
    }
    
    fmt.Println("Результат деления:", result)
}

6. Структуры данных (Массивы, Слайсы, Мапы)

В реальной бэкенд-разработке массивы фиксированной длины используются редко. Вместо них применяются динамические массивы — Слайсы (Slices), и ассоциативные массивы — Мапы (Maps).

package main

import "fmt"

func main() {
    // --- СЛАЙСЫ (Динамические массивы) ---
    clans := []string{"Alpha", "Beta"}
    clans = append(clans, "Kristall") // Добавляем элемент динамически
    
    for index, clanName := range clans {
        fmt.Printf("Клан %d: %s\n", index+1, clanName)
    }

    // --- МАПЫ (Словари / Хэш-таблицы) ---
    playerScores := make(map[string]int)
    playerScores["Vlad"] = 5000
    playerScores["Denis"] = 3400
    
    fmt.Println("Очки Влада:", playerScores["Vlad"])
}

7. Понятие об Указателях (Pointers) и работе с памятью

Go позволяет управлять памятью напрямую с помощью указателей. Когда вы передаете переменную в функцию обычным способом, Go делает её полную копию в памяти. Изменения внутри функции не меняют исходную переменную. Указатель же хранит адрес ячейки памяти, позволяя менять оригинал напрямую и экономить ресурсы сервера.

[ Переменная: currentScore ] ── лежит в ячейке памяти ──> [ Адрес: 0xc0000a20b0 ] (Значение: 100)
[ Указатель: scorePointer ] ── хранит этот адрес ──> [ Значение указателя: 0xc0000a20b0 ]
*scorePointer = 9999 ── меняет значение прямо по адресу ──> [ Адрес: 0xc0000a20b0 ] (Значение: 9999)

import "fmt"

// Функция принимает УКАЗАТЕЛЬ на int (*int) и меняет значение в исходной ячейке памяти
func updateScore(scorePointer *int) {
    *scorePointer = 9999 // Знаком * разыменовываем указатель и перезаписываем память
}

8. Создание HTTP-сервера для API

Напишем базовый микросервер, который готов отдавать данные в формате JSON для интеграции с вашими приложениями или играми.

package main

import (
    "fmt"
    "net/http"
)

func apiHandler(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    // Отправляем JSON-строку обратно клиенту
    fmt.Fprint(w, {"status": "success", "message": "Бэкенд работает отлично!"})
}

func main() {
    http.HandleFunc("/api/status", apiHandler)

    fmt.Println("Сервер бэкенда запущен на http://localhost:8080...")
    http.ListenAndServe(":8080", nil)
}
